# PDF草案比較アプリ

## 起動

Python 3.10以降を用意し、ターミナルでこのフォルダに移動して実行します。

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run pdf_compare_app.py
```

Windowsでは仮想環境を有効化するコマンドが異なります。起動後、Streamlitが表示するローカルURLをブラウザで開いてください。

## 主な操作

1. 左側から2つ以上のテキストPDFを選び、「PDFを読み込む」を押します。
2. 基準版と比較版（最大3版、合計4版まで）を選びます。同じ段落行に複数版を並べて比較できます。比較画面の「表示する版」で列を個別に表示／非表示にできます。
3. トピック数 `n` と自動マルチタグのしきい値を設定し、必要に応じて分類を更新します。自動分類では確率に応じて最大4タグを付けます。
4. 左サイドバーの「作業画面」から「比較」を選びます。Para番号は英文本文の先頭に表示しますが、文言差分の判定対象には含めません。段落番号を入力して「一番左の版のParaへ移動」を押すと、表示中の一番左の版の該当段落へ移動します。検索・トピック絞り込み・各種表示／編集チェックボックスもサイドバーにあります。英文中の `(a)`, `(b)` などの小文字アルファベット列挙は、それぞれ行を分けて表示します。「Watch操作」の表示切替で各段落のWatch追加／解除ボタンを表示・非表示にできます。ボタンから付箋画面へ移動せず段落全体のWatchを切り替えられます。検索語は英文中でオレンジ背景になります。「蛍光ペン」をオンにすると、段落ごとに原文の語句・文を指定して黄色で強調し、保存・解除できます。保存した強調はプロジェクトZIPと出力HTMLにも含まれます。「Watchを表示」をオンにすると登録済み付箋が段落直下に表示されます。「手動タグ指定」をオンにすると各段落カードで複数タグを選んで保存できます。ユーザー定義分類中は保存内容が学習例にも反映されます。「章立てを表示」でPDF内の章・節を表示できます。「メモを編集」をオンにすると、英文直下でメモを入力でき、入力内容は自動保存されます。
5. 「トピックと学習データ」で自動トピック名を編集できます。「推奨の14マルチタグを追加」を選ぶと、提示された基本6タグと追加8タグを登録してユーザー定義分類へ切り替えます。各段落に複数の正しいタグを割り当て、訂正例として保存できます。十分な正例・負例がそろったトピックはローカル分類器で確率を推定し、それ未満では類似度の参考値を表示します。
6. 「Watch付箋」で段落や文言を選んでメモを付けます。
7. CSVでメモをまとめて入出力する場合は「メモ」画面を使います。自動翻訳は行いません。
8. 「出力・保存」からHTMLまたは元PDF・学習データ・手動配置などを含むプロジェクトZIPを保存します。HTMLには各バージョンの表示／非表示チェックがあります。

## 注意点

- PDF本文はローカルで処理し、外部サービスに送信しません。
- 初版はテキスト層のあるPDFが対象です。スキャンPDFはOCRを別途行ってください。
- 段落抽出と自動対応付け、トピック分類は候補です。必要に応じて対応関係を手動で直してください。
- 「このPCに自動保存」が有効の場合、全セッションとPDFをアプリ本体と同じフォルダの隠しZIPに保存します。次回起動時に「前回の自動保存を復元」を選べます。
- HTML内のPDFページリンクを使う場合は、配布用ZIPを展開し、HTMLと同じ場所にある `pdfs` フォルダを保ってください。
- 学習例やメモを含むプロジェクトZIPを共有する場合は、保存内容を確認してください。
